SOBRE O PROJETO

Tecnologia para conectar pessoas ao conhecimento.

O Cloud Challenge é um projeto acadêmico para gerenciamento de eventos e inscrições da Semana Acadêmica da Faculdade Senac.

A aplicação utiliza HTML, CSS e JavaScript na interface, com API Django e banco de dados PostgreSQL planejado para os registros de inscrição.
